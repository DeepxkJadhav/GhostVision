# GhostVision ? AI Cyber Threat Intelligence Platform

[![FastAPI](https://img.shields.io/badge/FastAPI-005571?style=for-the-badge&logo=fastapi)](https://fastapi.tiangolo.com)
[![XGBoost](https://img.shields.io/badge/XGBoost-Anomaly--Detection-red?style=for-the-badge)](https://github.com/DeepxkJadhav/GhostVision)
[![MITRE ATT&CK](https://img.shields.io/badge/MITRE-ATT%26CK-orange?style=for-the-badge)](https://attack.mitre.org)
[![VirusTotal](https://img.shields.io/badge/VirusTotal-IoC_Enrichment-blue?style=for-the-badge)](https://www.virustotal.com)

GhostVision is an AI-driven cybersecurity intelligence platform that leverages machine learning anomaly detection to identify zero-day attacks, automate threat enrichment with **MITRE ATT&CK**, and score IoC indicators in real time.

## ?? Quickstart

```bash

pip install -r backend/requirements.txt

# 2. Start GhostVision API
uvicorn backend.app.main:app --port 8002 --reload
```

Interactive SOC Dashboard will be live at: `http://localhost:8002`
